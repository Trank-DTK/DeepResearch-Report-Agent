## 1. 产品概述

**智绘研报**是一个 DeepResearch 式长图文报告生成 Agent：用户输入一个研究问题，
系统自动完成「规划 → 联网检索 → 证据整理 → 分章撰写 → 图表生成与校验 → 报告合成」全流程，
输出一份带引用来源、图文混排的研究报告（Markdown / HTML / 可打印 PDF）。

**三重定位**：工程实践训练项目（首要）；未来 DeepResearch Agent 科研的实验平台；
软著登记 + GitHub 开源作品。

## 2. 用户与场景

- **目标用户**：需要快速获得"带来源、带图表"的调研报告的普通用户（学生、开发者、研究者）。
- **核心用户故事**：用户在网页输入"2025 年大模型推理加速的主流技术路线有哪些？"，
  看到 Agent 实时执行进度（规划、检索、画图、校验），几分钟后得到一份图文报告并可下载。

## 3. 功能需求（v1.0）

| 编号 | 功能 | 需求描述 | 验收标准 |
|---|---|---|---|
| FR-1 | 问题输入 | 单轮文本输入研究问题 | 输入合法性问题即可启动 |
| FR-2 | 规划 | LLM 将问题拆解为 3~6 个子问题（章节提纲） | 提纲为合法 JSON，章节数在配置范围内 |
| FR-3 | 联网检索 | 每子问题生成 2~3 个查询词，每个取前 5 条结果；检索器可插拔（Tavily 默认 / DDGS 兜底 / 用户自定义） | 检索结果带 URL 与摘要；结果本地缓存 |
| FR-4 | 网页抓取与证据库 | 抓取网页正文（trafilatura→beautifulsoup→摘要 三级降级），按子问题归档为证据库 | 每子问题 ≥3 条有效证据；不足时换词重搜或标记"证据不足" |
| FR-5 | 章节撰写 | 基于证据逐章生成正文，引用标注 `[n]` 必须对应证据库中的真实来源 | 正文引用 URL 全部存在于证据库（自检器可验） |
| FR-6 | 图表生成（FDV） | Find（从证据提取数据）→ Draw（matplotlib 绘图）→ Verify（TextVerifier 默认 / VisionVerifier 可选）校验图文一致，失败修正重画 | 每份报告含 ≥1 张通过校验的图表；图表嵌入报告对应章节 |
| FR-7 | 报告合成 | 输出 Markdown（权威格式）+ HTML（内置 CSS、图表 base64 内嵌、可打印 PDF） | 两格式均完整生成；HTML 浏览器打开美观 |
| FR-8 | 报告自检 | 合成后自动运行：引用完整性、防幻觉（正文 URL ∈ 证据库）、图表一致性、结构完整性、字数达标 | 界面上显示 ✅/⚠️ 自检清单并写入日志 |
| FR-9 | Web 界面 | Streamlit：输入、配置（LLM/检索器/校验器选择）、实时进度、报告预览、下载、自检展示 | GUI 第 3 周内可跑（软著截图红线） |
| FR-10 | 配置、日志与成本 | config.yaml + .env 密钥管理；运行日志（含 token 统计）；token 预算上限 | 更换渠道无需改代码；每轮运行成本可见 |

## 4. 非功能需求

- **可扩展性**：LLM / 检索器 / 抓取器 / 校验器四类组件走统一插件注册机制（`src/providers/` 自动发现）。
- **成本控制**：调试期本地模型免费；查询与正文全程缓存；预算上限兜底。
- **合规性**：源代码以原创 Python 为主（手写 Agent 内核）、含注释；GUI 截图与功能对应；v1.0 冻结与材料绑定。
- **可靠性**：LLM JSON 输出失败自动重试；网络失败三级降级；任一步骤失败不崩溃、记录并继续。

## 5. 明确不做（v1.0 非目标）

本地文档 RAG、多轮对话、用户账号、重前端（Vue）、LLM-as-judge 自动评分框架、定时任务、报告多语言。
（其中"自动评分"与"本地 RAG"为科研阶段切入方向。）
